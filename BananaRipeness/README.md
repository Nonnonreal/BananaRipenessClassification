# 🍌 BananaVision AI - Web Application Directory

โฟลเดอร์นี้เป็นส่วนของ **Web Application** ที่ให้บริการระบบตรวจจับและคัดแยกความสุกของกล้วย (YOLOv8 + MobileNetV2 4 Classes)

👉 **อ่านเอกสารคู่มือฉบับเต็มได้ที่ไฟล์หลัก:** [`../readme.md`](../readme.md)

---

### 🚀 คำสั่งรันด่วน (Quick Start)

```powershell
# 1. ใส่ Roboflow API Key ในไฟล์ .env
# 2. รัน Web Application
.venv\Scripts\python.exe run.py
```
*(หรือดับเบิลคลิกที่ไฟล์ `start.bat`)*

เปิดเบราว์เซอร์ที่: **http://127.0.0.1:5000**
